\caption{\textbf{The setting, the obstruction, and the repair that cannot work.}
\textbf{(a)}~A masked autoregressive image model \citep{li2024autoregressive} draws one continuous
KL16 token per patch from a small diffusion head. The tokenizer's width is fixed by a released
checkpoint, so we run the same pipeline in one dimension, where $\dd$ is free and an
acceptance-versus-$\dd$ curve exists at all.
\textbf{(b)}~Rejection is repaired from the residual $(p-q)_+$, so the emitted density equals the
target exactly (Eq.~\ref{eq:exact}); we use that identity as the zero point for every fidelity
metric, and \S\ref{sec:metric} reports one that failed it.
\textbf{(c)}~The transform-coding repair raises acceptance but leaves the orthogonal divergence
untested. The two effects are not independent, which is the subject of
Figure~\ref{fig:conservation}.}
