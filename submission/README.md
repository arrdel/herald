# ICLR 2027 submission

`main.tex` (9 pages of main text) and `appendix.tex` (10 pages), with `references.bib`.

## Building

The experiment host has no TeX installation, so the PDF committed here was produced with a static
[tectonic](https://tectonic-typesetting.github.io/) binary:

```bash
tectonic -X compile main.tex
```

For a standard TeX Live installation use the Makefile, which runs the usual
pdflatex/bibtex/pdflatex/pdflatex cycle:

```bash
make        # builds main.pdf
make pages  # reports the page count
make clean
```

Both routes are supported: `iclr2027_conference.sty` branches on the engine, using `times` under
pdfTeX and TeX Gyre Termes (metrically identical, addressed by file name) under the Unicode engines,
because a fetch-on-demand build has no system font database to resolve font names against.

## Layout

| file | contents |
|---|---|
| `main.tex` | the paper; `\iclrfinalcopy` switches off anonymisation and line numbers |
| `appendix.tex` | proofs, the CSpD derivation, full tables, the metric that failed, falsifiers |
| `references.bib` | bibliography, cited with natbib author-year |
| `iclr2027_conference.sty` | ICLR conference style. The official 2027 package is unpublished, so this is a self-contained reimplementation of the format, which has been stable for years |
| `figures/` | copied from `docs/figures/`, regenerated by the `scripts/run_e*.py` experiments |

## Regenerating the figures

Every figure is produced by a scripted experiment that writes a JSON artefact recording its own
commit, versions, and arguments alongside the image:

```bash
python scripts/run_e11.py                # figures/e11_acceptance_vs_d.png
python scripts/run_e11b.py               # figures/e11b_convergence.png
python scripts/run_e12a.py               # figures/e12a_random_projection.png
python scripts/run_e12_frontier.py       # figures/e12_frontier.png
python scripts/run_e12b.py               # E1.2b measurements
python scripts/analyze_e12b.py           # figures/e12b_collapse{,_compact}.png
python scripts/run_e14.py                # figures/e14_alignment.png
```
